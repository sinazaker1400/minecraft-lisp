unlimitted minecraft simulation at y direction, developed by ai tools

the commands for terminal:

to navigate to the file destination :

cd ~/quicklisp/local-projects/minecraft-lisp

to remove the compiled files :

rm -rf ~/.cache/common-lisp/sbcl-*/linux-x64-s/home/sina/quicklisp/local-projects/minecraft-lis


to run the project:

sbcl \
  --load ~/quicklisp/setup.lisp \
  --eval '(require :asdf)' \
  --eval '(asdf:load-system :minecraft :force t)'

 then :

 (in-package :minecraft-3d)

 then :

 (start-game)

 or with a custom seed (for example 123456789):

 (start-game 123456789)

 running in 1 line :
 
 sbcl \
  --load ~/quicklisp/setup.lisp \
  --eval '(require :asdf)' \
  --eval '(asdf:load-system :minecraft :force t)' \
  --eval '(minecraft-3d:start-game)' \
  --quit

or :

rm -rf ~/.cache/common-lisp/sbcl-*/linux-x64-s/home/sina/quicklisp/local-projects/minecraft-lisp/*
sbcl --load ~/quicklisp/setup.lisp --eval '(require :asdf)' --eval '(asdf:load-system :minecraft :force t)'


to push commit:
git -c http.proxy= -c https.proxy= push -u origin main 

or :

git push -u origin main

to zip the projects :
tar czf minecraft-src.tar.gz *.lisp *.asd
